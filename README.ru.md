# App Store Release Tools

[English](README.md) | [Русский](README.ru.md)

Подготавливает «Что нового» для App Store: копирует опубликованные тексты или использует вставленную таблицу переводов. Перед сохранением показывает сравнение с существующим черновиком.

## Настройка

Нужны Node.js 22+, доступ к приложению, API-ключ App Store Connect и существующий черновик **Prepare for Submission**.

1. В [App Store Connect](https://appstoreconnect.apple.com/) откройте профиль → **Individual API Key** и создайте ключ либо используйте существующий. Сохраните **Key ID**.
2. Сохраните скачанный `.p8` вне репозитория. Apple позволяет скачать его только один раз.
3. Скопируйте `asc-config.example.json` в `.asc-config.json` и укажите Key ID и путь к ключу. Для командного ключа также добавьте `issuerId`.

В Windows используйте `/` в путях, например `C:/Users/User/Downloads/AuthKey_KEY_ID.p8`. Конфигурация и ключи приватны и исключены из Git. Установка зависимостей не требуется.

## Запуск

Выберите один из трёх способов запуска из папки проекта:

- **Двойной клик:** запустите `Start.command` на macOS или `Start.bat` на Windows. Веб-интерфейс откроется в браузере; если этого не произошло, используйте адрес из терминала. Для остановки закройте терминал.
- **Веб-версия через терминал:** выполните `npm run web`. Для остановки нажмите `Ctrl+C`.
- **Терминальная версия:** выполните `npm start` в интерактивном терминале. Выберите приложение, платформу и источник, проверьте сравнение и подтвердите сохранение. Завершите вставленную таблицу точкой на отдельной строке.

По умолчанию интерфейс на английском. Используйте **EN / RU** в веб-версии или команды `npm start -- --lang ru` / `npm start -- --lang en`. Выбор общий для веб-версии и терминала и сохраняется локально в `.release-tools-preferences.json`, исключённом из Git. Язык интерфейса не меняет локализации заметок приложения.

## Сравнение и сохранение

Выберите опубликованную версию или таблицу переводов как источник. В сравнении для каждого языка показаны текущий текст черновика и предлагаемый текст. Перед подтверждением проверьте приложение, платформу, версию черновика, источник и языки.

- Опубликованная версия нужна только при копировании из версии. Для iOS и macOS утилита пытается определить текущую версию через App Store США. Если определить её не удалось, выберите вручную; можно выбрать и другую опубликованную версию.
- Меняется только «Что нового» существующих локализаций черновика. Утилита не создаёт черновик или локализации, не выбирает билд и не отправляет приложение на проверку.
- Языки без текста в источнике пропускаются. Тексты черновика заменяются только после подтверждения. Если черновик или источник изменился после сравнения, подготовьте сравнение заново.
- Сохранение может завершиться частично. Проверьте обновлённые и неуспешные языки, затем повторите сравнение перед новой попыткой; не считайте все изменения сохранёнными.

Веб-сервер слушает `127.0.0.1`. Он обращается к сервисам Apple через локальную конфигурацию; вводить API-ключ в браузере не нужно. Сводки операций отображаются в терминале.

## Таблица переводов

Вставьте Markdown-таблицу или данные из электронной таблицы с языками строками или столбцами. Кнопка **Скопировать промпт** в веб-версии и терминальный сценарий для таблицы дают промпт с языками выбранного черновика. Замените описание изменений и используйте промпт в выбранном инструменте перевода; само приложение переводы не генерирует.

Используйте точные названия языков из промпта или коды локалей. Неизвестные или неоднозначные названия нужно исправить перед сравнением; в терминале для повтора требуется перезапуск. Распознанные языки вне черновика показываются как пропущенные; языки черновика, отсутствующие в таблице, остаются без изменений. Проверяйте переводы и не добавляйте неподтверждённых изменений.
