# Accessibility

The web interface includes labeled controls, keyboard handling for the app picker, text comparisons in a table, and status announcements through live regions. A terminal interface is also available through `npm start`.

No formal accessibility audit is documented. Compatibility with particular assistive technologies and conformance to an accessibility standard have not been verified.

Report barriers with the browser or terminal, operating system, assistive technology if relevant, steps, and expected behavior. Use the bug report template and invented app data; do not attach credentials, private app data, or raw logs.
