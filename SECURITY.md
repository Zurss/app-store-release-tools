# Security

Report suspected vulnerabilities privately through this repository's **Security → Report a vulnerability** option when private vulnerability reporting is enabled. If the option is unavailable, do not disclose the vulnerability in a public issue; wait until a private reporting channel is available.

Include a minimal reproduction, affected version or commit, and expected impact. Never attach API keys, `.asc-config.json`, authorization tokens, private app data, or raw logs. Use invented values and a sanitized excerpt only when necessary.

For ordinary bugs, use the bug report template. For conduct concerns, see [Code of Conduct](CODE_OF_CONDUCT.md).
