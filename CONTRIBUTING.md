# Contributing

Use a bug report or feature request for a focused problem. Include reproduction steps and expected behavior; English and Russian reports are welcome. See [Security](SECURITY.md) for vulnerabilities.

Use Node.js 22+ and run `npm test` from the project root. No dependency installation is required. Tests use local fixtures; do not use real credentials or call Apple services in tests.

Keep pull requests focused, follow the existing style, and cover changed behavior where useful. Update English and Russian interface text and README instructions together. Explain the change and checks performed in the pull request.

Never commit configuration, keys, preferences, private app data, or raw logs. Redact screenshots and use invented data in reports and tests. Follow the [Code of Conduct](CODE_OF_CONDUCT.md).
