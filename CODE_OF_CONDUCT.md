# Code of Conduct

Be respectful and discuss the work. Harassment, discrimination, threats, personal attacks, and publishing someone else's private information are not welcome.

Maintainers may remove harmful content and limit participation. To report abusive GitHub content or behavior, use [GitHub's Report abuse tools](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam). Do not post private details in a public issue.
